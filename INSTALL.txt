📋 REQUIREMENTS:
  ✅ Python 3.7 or higher
  ✅ Microphone (for voice input)
  ✅ Internet connection (for browser automation)
  ✅ Chrome browser (recommended)

═══════════════════════════════════════════════════════════

🚀 QUICK INSTALL:

  WINDOWS:
    1. Double-click: install.bat
    2. Wait for installation to complete
    3. Run: python zarves_pro.py

  LINUX/MAC:
    1. Open terminal in this folder
    2. Run: chmod +x install.sh
    3. Run: ./install.sh
    4. Run: python3 zarves_pro.py

═══════════════════════════════════════════════════════════

📦 MANUAL INSTALL:

  Step 1: Install Python packages
    pip install -r requirements.txt

  Step 2: Run Zarves
    python zarves_pro.py

═══════════════════════════════════════════════════════════

⚠️ COMMON ISSUES:

  Problem: "Python not found"
  Solution: Install Python from python.org
           Make sure to check "Add to PATH"

  Problem: "Microphone not working"
  Solution: Check system permissions
           Windows: Settings → Privacy → Microphone
           Mac: System Preferences → Security → Microphone

  Problem: "PyAudio installation failed"
  Solution: This is optional - voice will still work
           Windows: pip install pipwin && pipwin install pyaudio
           Linux: sudo apt-get install python3-pyaudio
           Mac: brew install portaudio && pip install pyaudio

  Problem: "Browser not opening"
  Solution: Install Chrome browser
           Or modify code to use Firefox
