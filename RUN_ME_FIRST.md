# 🎯 START HERE - First Time User Guide

## 👋 Welcome to Zarves!

Zarves ek **voice-controlled AI assistant** hai jo **bina kisi API key** ke kaam karta hai!

---

## ⚡ Quick Start (3 Steps)

### Step 1: Install Dependencies
```bash
# Windows
install.bat

# Linux/Mac
chmod +x install.sh
./install.sh
```

### Step 2: Run Zarves
```bash
# Basic version
python zarves_advanced.py

# Pro version (recommended)
python zarves_pro.py
```

### Step 3: Start Talking!
```
Say: "Hello Zarves"
Say: "Open Google"
Say: "What's the time?"
```

## ❓ Common Questions

### Q: Do I need internet?
**A:** Only for opening websites. AI works offline!

### Q: Do I need API keys?
**A:** No! Completely free, no API keys needed.

### Q: Which languages work?
**A:** Hindi and English, both work!

### Q: Can I customize?
**A:** Yes! Edit the Python files.

### Q: Is it safe?
**A:** Yes! All code is open source.

## 🐛 Problems?

### Microphone not working?
→ Check system permissions

### Browser not opening?
→ Install Chrome browser

### Voice not recognized?
→ Speak clearly, reduce noise

### Module errors?
→ Run `pip install -r requirements.txt`
